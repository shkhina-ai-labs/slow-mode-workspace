# Literature Baseline (the floor)

All papers verified via direct arXiv search 2026-05-04. URLs are links.

## Architectures beyond Transformer

- [Mamba: Linear-Time Sequence Modeling with Selective State Spaces (Gu & Dao, 2023-2024)](https://arxiv.org/abs/2312.00752) — selective SSM, O(n) sequence length.
- [Mamba-3: Improved Sequence Modeling using State Space Principles (2026)](https://openreview.net/forum?id=HwCvaJOiCj)
- [Speed Always Wins: Survey on Efficient Architectures for LLMs (2025)](https://arxiv.org/html/2508.09834v1)
- Hybrids — Jamba (Mamba + attention + MoE).

## Mixture-of-experts / sparse routing

- [ERMoE: Eigen-Reparameterized MoE (2025)](https://arxiv.org/html/2511.10971v2)
- [Mixture of Sparse Attention (MoSA) (2025)](https://arxiv.org/html/2505.00315v1) — 27% better PPL at fixed compute.
- [Improving Routing in Sparse MoE with Graph of Tokens (2025)](https://arxiv.org/html/2505.00792v1)

- [Beyond Fact Retrieval: Episodic Memory for RAG with Generative Semantic Workspaces (2025)](https://arxiv.org/html/2511.07587v1)
- [Episodic Memory is the Missing Piece for Long-Term LLM Agents (Pink et al., 2025)](https://arxiv.org/pdf/2502.06975)
